# Agent Instructions

This file applies to coding agents working on the ICHU website. Follow the [project structure](CONTRIBUTING.md#project-structure), code quality, reuse, comment, asset, localization, interface, Gitflow, and review guidance in [CONTRIBUTING.md](CONTRIBUTING.md).

Before editing, check the current branch and working tree, preserve existing changes, and read any more specific `AGENTS.md` files along the path.

Do not create branches, commits, pushes, pull requests, merges, or delete branches unless the user asks. Do not add test infrastructure or tools unless requested.

Verify affected pages using existing project tools and report only checks actually performed.
